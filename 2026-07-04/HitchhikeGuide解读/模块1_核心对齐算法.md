## 一、PPO - 近端策略优化 (第5章)

### 1.1 核心思想

**问题**：普通策略梯度更新没有步长约束，一次不幸的批量更新可能把策略推向生成垃圾的区域，导致不可恢复的崩溃。

**解决方案历史**：
1. **TRPO (2015)**：约束新旧策略的KL散度，效果好但需要昂贵的二阶优化
2. **PPO (2017)**：用简单的裁剪目标实现类似稳定性，实现简单10倍

### 1.2 裁剪目标（核心创新）

```
PPO裁剪目标公式
═══════════════════════════════════════════════════════════════════

L_CLIP(θ) = E_t[min(r_t(θ)Â_t, clip(r_t(θ), 1-ε, 1+ε)Â_t)]

其中：
- r_t(θ) = π_θ(a_t|s_t) / π_θ_old(a_t|s_t)  概率比
- Â_t：优势估计
- ε：裁剪参数（通常0.1-0.2）

═══════════════════════════════════════════════════════════════════
```

**裁剪直觉 - 关键洞察**：

| 情况 | 优势Â | 概率比r | 行为 | 原因 |
|------|-------|---------|------|------|
| 好动作 | Â > 0 | r < 1+ε | 正常梯度 | 鼓励增加概率 |
| 好动作 | Â > 0 | r ≥ 1+ε | 梯度为0 | 已经增加够了，停止 |
| 坏动作 | Â < 0 | r > 1-ε | 正常梯度 | 鼓励减少概率 |
| 坏动作 | Â < 0 | r ≤ 1-ε | 梯度为0 | 已经减少够了，停止 |

**净效果**：策略每步最多变化±20%，防止灾难性崩溃和过度自信。

### 1.3 完整PPO损失

```
PPO完整损失函数
═══════════════════════════════════════════════════════════════════

L = L_CLIP - c₁(V_θ(s_t) - V_target)² + c₂H[π_θ(·|s_t)]
    ─────   ───────────────────────────   ─────────────────
    策略损失        价值损失                    熵奖励

参数设置：
- c₁ = 0.1（价值损失权重）
- c₂ = 0.01（熵奖励权重）
- ε = 0.1-0.2（裁剪参数）

═══════════════════════════════════════════════════════════════════
```

### 1.4 PPO梯度推导（6步）

```

步骤4：无约束代理的问题
- 重要性权重变得极端 → 高方差
- 策略进入未测试区域 → 奖励模型不可靠
- 灾难性崩溃

L_CLIP(θ) = E_t[min(r_t(θ)Â_t, clip(r_t(θ), 1-ε, 1+ε)Â_t)]

═══════════════════════════════════════════════════════════════════
```

### 1.5 为什么PPO有效

1. **策略梯度定理**：给出改进策略的方向
2. **重要性采样**：允许跨多个epoch复用旧策略数据
3. **裁剪**：防止重要性权重变得极端，保持更新安全
4. **min操作**：确保总是采取更保守的（裁剪/未裁剪）- 悲观下界

**结果**：使用一阶梯度实现单调改进，无需Hessian、共轭梯度或线搜索。

### 1.6 Rollout缓冲区

```
Rollout缓冲区生命周期
═══════════════════════════════════════════════════════════════════

阶段1：收集（Collect）
├── 活跃策略与环境交互
├── 填充新鲜轨迹
└── 70B模型，batch=128, max_tokens=512 → 最多65K令牌级转换

阶段2：训练（Train）
├── 计算GAE优势
├── 运行K个epoch（通常3-10）的小批量梯度下降
└── 使用裁剪目标更新策略权重

阶段3：清除（Purge）
├── 整个缓冲区完全清空
├── PPO是on-policy，旧策略数据不能复用
└── 比率r_t(θ)会变旧，裁剪保证会失效

═══════════════════════════════════════════════════════════════════
```

## 二、DPO - 直接偏好优化 (第6章)

### 2.1 核心思想

**动机**：PPO需要4个模型在内存中（策略、参考、奖励模型、价值头），复杂的RL基础设施，而且众所周知不稳定。

**DPO的核心问题**：能否跳过RL，直接从偏好数据学习？

**关键洞察**：RLHF目标下的最优策略（奖励最大化 + KL惩罚）有**闭式解**。我们可以推导出一个监督损失，隐式地优化相同目标。

### 2.2 数学推导

```
DPO数学推导
═══════════════════════════════════════════════════════════════════

步骤1：RLHF目标
max_π E_{x,y~π}[r(x,y)] - βD_KL[π||π_ref]

步骤2：最优解
π*(y|x) = (1/Z(x)) · π_ref(y|x) · exp(r(x,y)/β)

步骤3：重排表达奖励
r(x,y) = β·log(π*(y|x)/π_ref(y|x)) + β·log(Z(x))

步骤4：代入Bradley-Terry偏好模型
P(y_w ≻ y_l) = σ(r(y_w) - r(y_l))

Z(x)消掉了！

最终DPO损失：
L_DPO(θ) = -E_{(x,y_w,y_l)}[log σ(β·log(π_θ(y_w|x)/π_ref(y_w|x)) - β·log(π_θ(y_l|x)/π_ref(y_l|x)))]

═══════════════════════════════════════════════════════════════════
```

### 2.3 DPO实际做什么

定义**隐式奖励**：r̂(x,y) = β·log(π_θ(y|x)/π_ref(y|x))

DPO最小化交叉熵损失，其中"标签"是：**选择的响应应该比拒绝的响应有更高的隐式奖励**。

- **大β**：需要大边距 → 策略激进移动 → 风险遗忘
- **小β**：小边距就够 → 策略保持接近参考 → 保守

**参考模型的作用**：正则化器 - 策略必须通过显示偏好对齐来"证明"任何偏离是合理的。

### 2.4 梯度分析

```
DPO梯度分解
═══════════════════════════════════════════════════════════════════

∇_θL = -β · σ(-r̂_w + r̂_l) · [∇_θlogπ_θ(y_w|x) - ∇_θlogπ_θ(y_l|x)]
        ─────────────────────   ───────────────────────────────────────
              权重因子                    梯度方向

权重因子解释：
- 当模型当前偏好错误答案时：权重最大（≈0.5）→ 聚焦学习"混淆"对
- 当模型已经正确时：权重最小（≈0）→ 不过度拟合

梯度方向解释：
- 增加选择响应(y_w)的概率
- 减少拒绝响应(y_l)的概率

═══════════════════════════════════════════════════════════════════
```

### 2.5 具体DPO示例

```
DPO具体示例
═══════════════════════════════════════════════════════════════════

提示："向10岁孩子解释量子纠缠"

选择(y_w)："想象你有两个魔法硬币。当你抛一个看到是正面时，
           另一个瞬间变成反面，无论它们相距多远！"
logπ_θ(y_w|x) = -15.3, logπ_ref(y_w|x) = -16.1

拒绝(y_l)："量子纠缠是一种两个粒子变得相关的现象，使得一个
           粒子的量子状态无法独立描述。"
logπ_θ(y_l|x) = -12.8, logπ_ref(y_l|x) = -12.5

隐式奖励：
r̂_w = 0.1 × (-15.3 - (-16.1)) = 0.08
r̂_l = 0.1 × (-12.8 - (-12.5)) = -0.03

损失输入：σ(0.08 - (-0.03)) = σ(0.11) = 0.527
损失：-log(0.527) = 0.64

解释：模型勉强偏好选择的响应。梯度将大力推动。

训练后：选择概率增加，拒绝概率减少，直到边距稳定在1/(2β)附近。

═══════════════════════════════════════════════════════════════════
```

### 2.6 DPO前向传播（逐步）

```
DPO前向传播步骤
═══════════════════════════════════════════════════════════════════

步骤1：拼接
形成两个序列：[x; y_w] 和 [x; y_l]
在批次内填充到相等长度

步骤2：前向传播（策略π_θ）
运行两个序列通过模型
在每个响应位置收集logits

步骤3：提取对数概率
在响应的每个位置t，取logsoftmax(logits_t)[y_t]
即实际令牌的对数概率

步骤4：令牌求和
logp_chosen = Σ_{t∈响应位置} logπ_θ(y_t^w|x, y_{<t}^w)
logp_rejected = Σ_{t∈响应位置} logπ_θ(y_t^l|x, y_{<t}^l)

步骤5：减去参考（预计算或第二次前向传播）
ratio_w = logp_chosen - ref_logp_chosen
ratio_l = logp_rejected - ref_logp_rejected

步骤6：计算损失
L = -log σ(β · (ratio_w - ratio_l))

步骤7：反向传播
梯度从步骤5→4→3→2流回，更新θ

═══════════════════════════════════════════════════════════════════
```

### 2.7 令牌级梯度分析

**关键问题**：每个令牌都获得梯度吗？**是的。**

```
令牌级梯度
═══════════════════════════════════════════════════════════════════

∂L/∂logits_t^(w) = -σ(-β·h_θ) · β · ∂logπ_θ(y_t^w|·)/∂logits_t^(w)
                    ──────────
                    缩放因子（对两个序列的所有令牌共享）

缩放因子行为：
- h_θ小（模型无法区分选择和拒绝）：缩放≈0.5 → 强梯度，积极学习
- h_θ大（模型已经偏好选择）：缩放≈0 → 可忽略梯度，不过度拟合

对选择令牌的影响：概率增加（对数概率向上推）
对拒绝令牌的影响：概率减少（对数概率向下推）

相对于参考：只有与π_ref的差异才重要

═══════════════════════════════════════════════════════════════════
```

### 2.8 β选择指南

| β值 | 效果 | 适用场景 |
|-----|------|----------|
| 小 (0.05-0.1) | 更激进更新 | 偏好数据质量高 |
| 中 (0.1-0.5) | 平衡 | 通用场景 |
| 大 (0.5-1.0) | 保守更新 | 噪声数据、防止过拟合 |

## 三、GRPO - 群组相对策略优化 (第7章)

### 3.1 核心思想

**GRPO** 是专为语言模型设计的强化学习算法，**消除了对独立价值网络（评论家）的需求**。

由DeepSeek在DeepSeekMath工作中引入，后扩展到DeepSeek-R1，GRPO已迅速成为LLM训练的主导RL方法。

**核心思想**：不训练神经网络来预测期望奖励（PPO中的评论家），而是通过**生成多个响应并使用群组奖励统计作为基线**来经验性地估计。

### 3.2 PPO价值模型的三大问题

```
PPO价值模型的问题
═══════════════════════════════════════════════════════════════════

问题1：内存
- 价值头共享策略骨干（70B模型约140GB）
- 如果分开，内存翻倍

问题2：准确性
- 预测部分序列的期望奖励极其困难
- 价值函数经常出错 → 错误的优势 → 错误的梯度方向

问题3：训练
- 价值头需要大量样本才能收敛
- 在早期RL中，给出噪声预测， destabilize策略学习

═══════════════════════════════════════════════════════════════════
```

### 3.3 GRPO算法

```
GRPO算法流程
═══════════════════════════════════════════════════════════════════

步骤1：对每个提示x，采样G个补全
{y_1, ..., y_G} ~ π_θ(·|x)

步骤2：评分每个响应
r_i = R(x, y_i)

步骤3：群组内标准化
Â_i = (r_i - μ_G) / σ_G
其中 μ_G = (1/G)Σ_j r_j, σ_G = std({r_j})

步骤4：应用PPO风格的裁剪更新
L = E[min(r_t(θ)Â_t, clip(r_t(θ), 1±ε)Â_t)] - βD_KL[π_θ||π_ref]

═══════════════════════════════════════════════════════════════════
```

### 3.4 为什么群组标准化有效

```
群组标准化的直觉
═══════════════════════════════════════════════════════════════════

群组均值近似V(s)：
- 如果对同一提示采样足够多响应
- 它们的平均奖励是期望奖励的蒙特卡洛估计 = 价值函数

高于均值 = 好动作：
- Â_i > 0 意味着这个响应比这个提示的平均响应好
- 强化它

低于均值 = 坏动作：
- Â_i < 0 意味着比平均差
- 抑制它

标准化：
- 除以σ_G确保优势在不同奖励范围的提示间是尺度不变的

═══════════════════════════════════════════════════════════════════
```

### 3.5 DeepSeek-R1突破

```
DeepSeek-R1突破
═══════════════════════════════════════════════════════════════════

纯GRPO + 二元正确性奖励：
- r = 1 如果答案正确
- r = 0 如果答案错误

在数学/代码上训练的结果：
- 自发发展出链式思考推理
- 自发发展出自我验证
- 自发发展出错误纠正

没有任何明确指令这样做！

关键洞察：RL训练本身可以涌现出复杂的推理行为

═══════════════════════════════════════════════════════════════════
```

### 3.6 群组大小分析

| 群组大小G | 信号质量 | 计算成本 | 何时使用 |
|-----------|---------|---------|---------|
| 2 | 非常噪声（抛硬币） | 低 | 永不推荐 - 太噪声 |
| 4 | 中等 | 中 | 快速实验，简单任务（通过率>50%） |
| **8** | **好（标准）** | **高** | **默认。大多数任务的良好平衡** |
| 16 | 优秀 | 非常高 | 困难任务（通过率<20%），需要多次尝试获得正例 |
| 32 | 近完美 | 极高 | 只在有大量计算且任务非常困难时 |

**关键规则**：群组必须包含成功和失败！

- 如果所有G个响应都正确（r_i=1）：所有优势=0，无学习信号！
- 如果所有都错：同样问题。提示难度必须匹配模型能力。

**金发姑娘规则**：过滤提示到当前模型20-80%通过率。每500步重新过滤。

### 3.7 GRPO变体家族

```
GRPO变体家族
═══════════════════════════════════════════════════════════════════

标准GRPO
│
├── 多样性增强变体
│   ├── DAPO（动态自适应策略优化）
│   │   └── "无重复"惩罚：拒绝群组内重复响应
│   │
│   └── SAPO（软自适应策略优化）
│       └── 软归一化替代硬标准化
│
├── 偏差修正变体
│   ├── Dr. GRPO（去偏奖励GRPO）
│   │   └── 修正群组大小偏差
│   │
│   └── GDPO（群组奖励解耦策略优化）
│       └── 解耦不同奖励信号
│
├── 效率改进变体
│   ├── 2-GRPO（最小两rollout GRPO）
│   │   └── 仅需2个响应，最低计算成本
│   │
│   └── TIS/MIS（截断/掩码重要性采样）
│       └── 减少重要性采样方差
│
├── 扩展变体
│   ├── GSPO（群组序列策略优化）
│   │   └── 扩展到序列级优化

│   │   └── 变分推断视角

    ├── ScaleRL/CISPO

        └── 使用序数排名而非基数奖励

═══════════════════════════════════════════════════════════════════
```

### 3.8 关键GRPO变体详解

#### DAPO（动态自适应策略优化）

**核心改进**：解决群组内多样性不足问题

- "无重复"惩罚：拒绝群组内重复响应，强制探索
- 如果所有N个响应相同：优势为零，无学习信号
- 如果响应太多样（随机）：奖励信号噪声大，学习慢

**甜蜜点**：给定温度τ=0.8-1.0，确保不同响应用于有意义的比较

#### Dr. GRPO（去偏奖励GRPO）

**核心改进**：修正群组大小偏差

问题：不同群组大小的标准化会引入偏差
解决：调整标准化公式以消除群组大小依赖

#### 2-GRPO（最小两rollout GRPO）

**核心改进**：最小化计算成本

- 仅需2个响应：一个好一个坏
- 最低计算成本
- 适合快速迭代和资源受限场景

## 四、其他偏好优化方法 (第8章)

### 4.1 方法全景

```
偏好优化方法全景
═══════════════════════════════════════════════════════════════════

基于成对偏好数据：
├── 标准DPO
├── Online DPO（在线采样 + DPO更新）
├── f-DPO, Robust DPO, TR-DPO, SimPO等变体
└── Iterative RPO（迭代改进）

不需要成对偏好数据：
├── KTO（Kahneman-Tversky优化）
│   └── 只需正/负反馈，基于前景理论
├── IPO（身份偏好优化）
│   └── 添加身份正则化防止过拟合
└── ORPO（优势比偏好优化）
    └── 直接优化优势比

推理时方法：
└── Best-of-N采样（拒绝采样）
    └── 采样N个响应，选择最高奖励的

═══════════════════════════════════════════════════════════════════
```

### 4.2 Online DPO vs Offline DPO vs PPO

| 特性 | Offline DPO | Online DPO | PPO |
|------|-------------|------------|-----|
| 数据来源 | 预收集的偏好数据 | 在线采样 + 偏好 | 在线采样 + 奖励 |
| 需要奖励模型 | ❌ | ❌ | ✅ |
| 需要价值网络 | ❌ | ❌ | ✅ |
| 训练稳定性 | 高 | 中 | 中 |
| 样本效率 | 低 | 中 | 高 |
| 分布偏移 | 有 | 无 | 无 |

### 4.3 KTO - Kahneman-Tversky优化

**动机**：不需要成对偏好数据，只需正/负反馈

**损失函数**：基于前景理论
- 人类对损失比收益更敏感（损失厌恶）
- 正例和负例不对称处理

**适用场景**：
- 只有用户点赞/点踩数据
- 没有成对比较数据
- 数据收集成本低

### 4.4 IPO - 身份偏好优化

**动机**：解决DPO的过拟合问题

**损失函数**：添加身份正则化
- 防止策略过度偏离参考
- 特别适合噪声偏好数据

**适用场景**：
- 偏好数据噪声较大
- 需要更保守的更新

### 4.5 ORPO - 优势比偏好优化

**动机**：简化训练流程

**损失函数**：直接优化优势比
- 无需参考模型
- 训练更简单

**适用场景**：
- 需要更简单的训练流程
- 资源受限场景

### 4.6 Best-of-N采样

**动机**：推理时提升质量，无需额外训练

**算法**：
1. 生成N个响应
2. 评分所有响应
3. 返回最高奖励的

**缩放定律**：性能随N对数增长

**权衡**：增加推理计算成本换取质量

## 六、核心公式速查表

### 6.1 PPO

```
概率比：r_t(θ) = π_θ(a_t|s_t) / π_θ_old(a_t|s_t)

裁剪目标：L_CLIP = E[min(r_t Â_t, clip(r_t, 1-ε, 1+ε) Â_t)]

完整损失：L = L_CLIP - c₁L_VF + c₂H(π)

价值损失：L_VF = (V_θ(s_t) - V_target)²

熵：H(π) = -Σ_a π(a|s) log π(a|s)
```

### 6.2 DPO

```
DPO损失：L = -E[log σ(β(r̂_w - r̂_l))]

隐式奖励：r̂(x,y) = β log(π_θ(y|x) / π_ref(y|x))

梯度：∇L = -β · σ(-r̂_w + r̂_l) · [∇logπ_θ(y_w) - ∇logπ_θ(y_l)]
```

### 6.3 GRPO

```
标准化优势：Â_i = (r_i - μ_G) / σ_G

群组均值：μ_G = (1/G) Σ_j r_j

群组标准差：σ_G = std({r_j})

目标：L = E[min(r_t Â_t, clip(r_t, 1±ε) Â_t)] - βD_KL[π_θ||π_ref]
```

### 6.4 GAE

```
优势估计：A_t = Σ_{l=0}^∞ (γλ)^l δ_{t+l}

TD误差：δ_t = r_t + γV(s_{t+1}) - V(s_t)
```

## 七、最佳实践总结

### 7.1 PPO最佳实践

1. **学习率**：从1e-5开始，逐步调整
2. **裁剪参数**：ε=0.1-0.2
3. **GAE参数**：λ=0.95, γ=0.99
4. **批量大小**：至少64，越大越稳定
5. **训练轮数**：每次收集数据后1-4个epoch
6. **监控指标**：策略损失、价值损失、熵、KL散度

### 7.2 DPO最佳实践

1. **β选择**：从0.1开始，根据数据质量调整
2. **学习率**：5e-7到1e-6（比PPO低）
3. **训练轮数**：通常1轮（DPO容易过拟合）
4. **批量大小**：16-32
5. **数据格式**：确保chosen/rejected质量差异明显
6. **监控指标**：chosen奖励、rejected奖励、边距

### 7.3 GRPO最佳实践

1. **群组大小**：默认G=8，困难任务用16
2. **温度**：τ=0.8-1.0确保多样性
3. **KL系数**：β=0.04-0.1
4. **提示过滤**：保持20-80%通过率
5. **使用vLLM**：加速生成（关键！）
6. **监控指标**：群组奖励分布、优势分布、KL散度
